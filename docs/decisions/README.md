# Décisions d'architecture (ADR)

Chaque choix structurant est écrit ici, une fois, avec sa raison. Pour changer un choix, on écrit une nouvelle décision qui remplace l'ancienne (on n'efface pas l'histoire). Cela permet à un nouveau contributeur de comprendre *pourquoi* le projet est comme il est.

| 0002 | Plan de contrôle en Node.js + TypeScript | acceptée |
| 0003 | Licence AGPL-3.0 | acceptée |
| 0004 | Projet autonome, public, sans dépendance à PimsWork | acceptée |
| 0005 | Construire de zéro, pas d'extension d'un outil existant | acceptée |
| 0006 | Modèle d'exposition réseau et d'authentification de l'accès distant | acceptée |
