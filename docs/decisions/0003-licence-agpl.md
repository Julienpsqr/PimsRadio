# 0003 — Licence AGPL-3.0
**Date** 2026-11-18 · **Statut** acceptée

**Décision.** AGPL-3.0-or-later.

**Raison.** Même famille que Liquidsoap, Icecast et ODR. Un service en ligne basé sur PimsRadio doit partager ses modifications : protège les radios contre un SaaS fermé qui reprendrait le travail.

**À faire.** Ajouter le texte officiel `LICENSE` (gnu.org) et les en-têtes SPDX dans les fichiers sources.
