# Contributing / Contribuer

**EN** — The project is in early development: the most useful contribution today is **feedback** (open an issue) if you run or volunteer at a community radio. Principles: easy install first; few, pinned, justified dependencies; tests required; decisions written in `docs/decisions/`; docs and UI in **French and English**, no hard-coded text; by contributing you agree your code is released under AGPL-3.0.

**FR** — Le projet est en développement initial : la contribution la plus utile aujourd'hui est votre **retour** (ouvrez un ticket) si vous animez une radio associative. Principes : installation simple d'abord ; peu de dépendances, épinglées et justifiées ; tests obligatoires ; décisions écrites dans `docs/decisions/` ; docs et interface en **français et anglais**, aucun texte en dur ; en contribuant, vous acceptez la publication sous AGPL-3.0.
