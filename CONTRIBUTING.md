# Contribuer à PimsRadio

Le projet est en phase de conception : le plus utile aujourd'hui est de **donner ton retour** (ouvre un ticket) si tu animes ou gères une radio associative.

Principes pour durer :
- **Simple à installer** avant tout : toute fonction qui complique l'installation doit se justifier.
- **Peu de dépendances**, épinglées et justifiées.
- **Tests obligatoires** pour toute nouvelle fonction ; l'antenne ne doit jamais dépendre d'un bogue du plan de contrôle.
- **Décisions écrites** dans `docs/decisions/` (une courte note par choix structurant).
- Interface et docs en **français d'abord, anglais ensuite** ; aucun texte en dur dans le code.
- Licence : en contribuant, tu acceptes que ton code soit publié sous AGPL-3.0.

Le plan complet est dans [docs/PLAN.md](docs/PLAN.md).
